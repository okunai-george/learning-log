Управление пользователями и группами в Linux: кто есть кто в системе и кто что может.

---

## 1. Users and Groups — Пользователи и группы

Linux — многопользовательская система. У каждого пользователя есть свой **UID** (User ID), а у каждой группы — **GID** (Group ID). Каждый файл и процесс принадлежит какому-то пользователю и группе.

```bash
whoami # Показывает имя текущего пользователя
id # Показывает UID, GID и все группы текущего пользователя
groups # Показывает, в каких группах состоит пользователь

```

```
Вывод (id):
uid=1000(grigorijklopov) gid=1000(grigorijklopov) groups=1000(grigorijklopov),27(sudo)

```

- Каждый пользователь имеет **основную группу** (primary group) — обычно создаётся автоматически вместе с пользователем и совпадает с его именем
- Пользователь может состоять и в **дополнительных группах** (secondary groups) — они дают доступ к общим ресурсам (например, группа `sudo` даёт права администратора)
- Группы — это удобный способ выдавать права сразу многим пользователям, а не каждому по отдельности

## 2. root — Суперпользователь

`root` — это встроенный аккаунт администратора с UID `0`. У него нет ограничений: он может читать, писать и удалять что угодно в системе.

```bash
sudo whoami

```

```
Вывод: root

```

- `sudo` (superuser do) — временно выполняет одну команду от имени root, спрашивая пароль текущего пользователя
- `su` (switch user) — переключает всю сессию на другого пользователя (без имени — на root), спрашивает пароль *_того_ пользователя, на которого переключаешься
- `su -` — то же самое, но ещё и подгружает окружение (переменные, домашнюю папку) целевого пользователя, как будто тот залогинился с нуля
- Работать под root напрямую в повседневных задачах считается плохой практикой — используют `sudo` для конкретных команд, чтобы минимизировать риск

```bash
su - # Переключиться на root (с окружением root)
su - ivan # Переключиться на пользователя ivan
sudo apt update # Выполнить одну команду от root, оставаясь собой

```

## 3. /etc/passwd — Файл учётных записей

Текстовый файл, где хранится основная информация о каждом пользователе системы. Доступен на чтение всем.

```bash
cat /etc/passwd

```

```
Вывод: grigorijklopov:x:1000:1000:Grigorij Klopov:/home/grigorijklopov:/bin/bash

```

Структура строки (7 полей через `:`):

```
username : password : UID : GID : GECOS (описание) : home directory : shell

```

- `username` — имя пользователя для входа
- `password` — `x` означает, что реальный хэш пароля хранится не здесь, а в `/etc/shadow`
- `UID` — уникальный числовой идентификатор пользователя (0 = root, обычно 1000+ — обычные пользователи)
- `GID` — идентификатор основной группы
- `GECOS` — произвольное описание (полное имя, телефон и т.д.)
- `home directory` — путь к домашней папке пользователя
- `shell` — какая оболочка запускается при входе (`/bin/bash`, `/bin/sh`, `/usr/sbin/nologin` — запрет входа)

## 4. /etc/shadow — Файл паролей

Хранит зашифрованные пароли и данные об их сроке действия. В отличие от `/etc/passwd`, читать его может только root.

```bash
sudo cat /etc/shadow

```

```
Вывод: grigorijklopov:$6$xyz...hash...:19700:0:99999:7:::

```

Структура строки (9 полей через `:`):

```
username : password hash : last change : min : max : warn : inactive : expire : reserved

```

- `password hash` — зашифрованный пароль. Если стоит `!` или `*` — вход по паролю заблокирован
- `last change` — дата последней смены пароля (в днях с 1 января 1970 года)
- `min` / `max` — минимальное и максимальное число дней между сменами пароля
- `warn` — за сколько дней предупреждать пользователя об истечении пароля
- `inactive` — сколько дней аккаунт может быть неактивным после истечения пароля, прежде чем заблокируется
- `expire` — дата истечения самого аккаунта

```bash
sudo passwd -l ivan # (lock) Заблокировать пароль пользователя
sudo passwd -u ivan # (unlock) Разблокировать пароль пользователя
sudo chage -l ivan # Посмотреть информацию о сроке действия пароля

```

## 5. /etc/group — Файл групп

Хранит список всех групп системы и их дополнительных участников.

```bash
cat /etc/group

```

```
Вывод: sudo:x:27:grigorijklopov,ivan

```

Структура строки (4 поля через `:`):

```
group name : password : GID : список участников (через запятую)

```

- `group name` — имя группы
- `password` — почти всегда `x` (групповые пароли сегодня практически не используются)
- `GID` — числовой идентификатор группы
- список участников — только те, для кого эта группа **дополнительная**; те, у кого она основная, здесь не перечисляются (это видно только в `/etc/passwd`)

## 6. User Management Tools — Утилиты управления пользователями

Команды для создания, изменения и удаления пользователей и групп.

### Создание пользователя

```bash
sudo useradd -m ivan # (make home dir) Создать пользователя с домашней папкой
sudo adduser ivan # Интерактивный аналог useradd (спросит пароль, имя и т.д.)
sudo passwd ivan # Задать пароль новому пользователю

```

```
Вывод: New password: / Retype new password: / passwd: password updated successfully

```

- `useradd` — низкоуровневая команда, по умолчанию не создаёт пароль и (без `-m`) не создаёт домашнюю папку
- `adduser` — "дружелюбная" обёртка над `useradd`, задаёт вопросы пошагово (есть не на всех дистрибутивах из коробки)

### Изменение пользователя

```bash
sudo usermod -aG sudo ivan # (append Group) Добавить в группу, не потеряв остальные
sudo usermod -s /bin/zsh ivan # Сменить оболочку по умолчанию
sudo usermod -d /new/home ivan # Сменить домашнюю папку

```

- Флаг `-a` (append) обязателен вместе с `-G` — без него `usermod -G` полностью **заменит** список групп пользователя, а не дополнит его

### Удаление пользователя

```bash
sudo userdel ivan # Удалить пользователя (домашняя папка останется)
sudo userdel -r ivan # (remove) Удалить пользователя вместе с домашней папкой

```

### Работа с группами

```bash
sudo groupadd developers # Создать новую группу
sudo groupdel developers # Удалить группу
sudo gpasswd -d ivan developers # Удалить пользователя из группы

```
