# Text-Fu

Работа с текстовыми потоками, перенаправлением и обработкой текста в Linux.

---

## 1. stdout (Standard Output) — Стандартный вывод

Поток, в который процесс по умолчанию пишет свой результат (по умолчанию — экран).

```bash
echo Hello World!

```

```
Вывод: Hello World!

```

Перенаправление:

```bash
echo Hello World! > file.txt # Записывает вывод в файл (перезаписывает содержимое)
echo Hello World! >> file.txt # Дописывает вывод в конец файла (не стирая старое)

```

- `>` — если файла нет, создаст его; если есть — полностью перезапишет
- `>>` — если файла нет, создаст его; если есть — допишет в конец

---

## 2. stdin (Standard In) — Стандартный ввод

Поток, из которого процесс получает данные (по умолчанию — клавиатура).

```bash
cat < file.txt

```

```
Вывод: содержимое file.txt выводится на экран

```

- `<` — перенаправляет содержимое файла на stdin команды (вместо ввода с клавиатуры)
- команда `cat` без `<` сама умеет принимать файл как аргумент, но `<` явно показывает механизм перенаправления ввода

---

## 3. stderr (Standard Error) — Стандартный вывод ошибок

Отдельный от stdout поток, куда процесс пишет сообщения об ошибках (по умолчанию тоже экран).

У каждого потока свой номер (файловый дескриптор):

```
0 — stdin
1 — stdout
2 — stderr

```

```bash
ls несуществующая_папка 2> errors.txt

```

```
Вывод: сообщение об ошибке уходит не на экран, а в errors.txt

```

- `2>` — перенаправляет именно stderr (номер дескриптора обязателен, иначе уйдёт stdout)
- `2>>` — дописывает ошибки в конец файла
- `> file 2>&1` — перенаправить и stdout, и stderr в один файл

---

## 4. pipe и tee — Конвейер и разветвление потока

`|` (pipe) передаёт stdout одной команды на stdin другой. `tee` пишет поток одновременно на экран и в файл.

```bash
echo Hello World! | grep Hello

```

```
Вывод: Hello World!

```

```bash
ls | tee list.txt

```

```
Вывод: список файлов выводится на экран И сохраняется в list.txt

```

- `|` — соединяет команды в цепочку: `команда1 | команда2 | команда3`
- `tee` — по умолчанию перезаписывает файл, флаг `-a` дописывает в конец (как `>>`)

## 5. env (Environment) — Переменные окружения

Именованные значения, доступные процессам системы (пути, язык, домашняя папка и т.д.)

```bash
echo $HOME

```

```
Вывод: /Users/grigorijklopov

```

```bash
env # Показать все переменные окружения
export MYVAR="hello" # Создать свою переменную окружения
echo $MYVAR

```

```
Вывод: hello

```

- `env` — выводит список всех переменных окружения
- `export` — делает переменную доступной дочерним процессам
- `$PATH` — одна из ключевых переменных: список папок, где ищутся исполняемые команды

## 6. cut — Вырезание частей строки

Извлекает часть каждой строки: по символам, байтам или полям (колонкам).

```bash
echo "little:ball:of:fur" | cut -d ":" -f 3

```

```
Вывод: of

```

Флаги:

```bash
cut -c 1-5 file.txt # (characters) Вырезать символы с 1 по 5
cut -f 2 file.txt # (field) Вырезать 2-е поле (по умолчанию разделитель — TAB)
cut -d "," -f 1,3 file.txt # (delimiter) Задать свой разделитель и несколько полей через запятую

```

## 7. paste — Склейка строк из файлов

Объединяет строки нескольких файлов построчно, по горизонтали (по умолчанию через TAB).

```bash
paste file1.txt file2.txt

```

```
Вывод: построчно объединённое содержимое file1.txt и file2.txt через TAB

```

Флаги:

```bash
paste -d "," file1.txt file2.txt # (delimiter) Задать свой разделитель вместо TAB
paste -s file1.txt # (serial) Склеить все строки одного файла в одну строку

```

## 8. head — Начало файла

Выводит первые строки файла (по умолчанию 10).

```bash
head file.txt

```

```
Вывод: первые 10 строк файла

```

Флаги:

```bash
head -n 5 file.txt # Показать первые 5 строк
head -c 20 file.txt # (characters) Показать первые 20 символов

```

---

## 9. tail — Конец файла

Выводит последние строки файла (по умолчанию 10).

```bash
tail file.txt

```

```
Вывод: последние 10 строк файла

```

Флаги:

```bash
tail -n 5 file.txt # Показать последние 5 строк
tail -f file.txt # (follow) Следить за файлом в реальном времени (удобно для логов)

```

## 10. expand и unexpand — Табы ↔ пробелы

`expand` превращает табы в пробелы, `unexpand` — наоборот.

```bash
expand -t 4 file.txt

```

```
Вывод: все табы в файле заменены на 4 пробела

```

```bash
unexpand -a file.txt

```

```
Вывод: последовательности пробелов заменены на табы

```

- `expand -t N` — задать ширину таба в пробелах
- `unexpand -a` — заменять пробелы табами не только в начале строк, но и везде

## 11. join и split — Слияние по ключу и разбиение файла

`join` объединяет две строки из разных файлов по общему полю (как JOIN в SQL). `split` разбивает один большой файл на несколько маленьких.

```bash
join file1.txt file2.txt

```

```
Вывод: строки из file1 и file2 объединены по совпадающему первому полю

```

```bash
split -l 100 bigfile.txt part_

```

```
Вывод: bigfile.txt разбит на файлы part_aa, part_ab, ... по 100 строк в каждом

```

- `join -1 N -2 M` — указать номера полей для сравнения в первом и втором файле (по умолчанию оба файла должны быть отсортированы по этому полю)
- `split -l N` — (lines) разбить по N строк
- `split -b N` — (bytes) разбить по N байт

## 12. sort — Сортировка строк

Сортирует строки файла (по умолчанию по алфавиту).

```bash
sort file.txt

```

```
Вывод: строки файла в алфавитном порядке

```

Флаги:

```bash
sort -r file.txt # (reverse) В обратном порядке
sort -n file.txt # (numeric) Сортировка по числовому значению, а не по алфавиту
sort -u file.txt # (unique) Убрать повторяющиеся строки при сортировке
sort -k 2 file.txt # (key) Сортировать по 2-му полю

```

## 13. tr (Translate) — Замена и удаление символов

Заменяет или удаляет символы в потоке (работает только со stdin, не с файлами напрямую).

```bash
echo "hello" | tr 'l' 'L'

```

```
Вывод: heLLo

```

Флаги:

```bash
tr -d 'a' # (delete) Удалить все символы 'a' из потока
tr -s ' ' # (squeeze) Сжать повторяющиеся пробелы в один
tr 'a-z' 'A-Z' # Перевести весь текст в верхний регистр

```

## 14. uniq (Unique) — Удаление повторов

Убирает соседние повторяющиеся строки (важно: строки должны идти подряд, поэтому часто используют после `sort`).

```bash
sort file.txt | uniq

```

```
Вывод: список строк без соседних дубликатов

```

Флаги:

```bash
uniq -c file.txt # (count) Показать, сколько раз повторяется каждая строка
uniq -d file.txt # (duplicate) Показать только те строки, которые повторяются

```

## 15. wc и nl — Подсчёт и нумерация строк

`wc` (word count) считает строки, слова и символы. `nl` (number lines) нумерует строки файла.

```bash
wc file.txt

```

```
Вывод: 10 50 300 file.txt (строк слов байт)

```

Флаги wc:

```bash
wc -l file.txt # (lines) Только количество строк
wc -w file.txt # (words) Только количество слов
wc -c file.txt # (characters/bytes) Только количество байт

```

```bash
nl file.txt

```

```
Вывод: файл с номерами строк слева

```

## 16. grep — Поиск по шаблону

Ищет строки, соответствующие шаблону (в том числе регулярным выражениям), и выводит их.

```bash
grep "USA" file.txt

```

```
Вывод: все строки файла, содержащие "USA"

```

Флаги:

```bash
grep -i "usa" file.txt # (ignore case) Игнорировать регистр
grep -v "USA" file.txt # (invert) Показать строки, где совпадения НЕТ
grep -r "USA" ./folder # (recursive) Искать по всем файлам в папке рекурсивно
grep -n "USA" file.txt # (number) Показать номера строк с совпадением
grep -c "USA" file.txt # (count) Показать количество совпавших строк

```
