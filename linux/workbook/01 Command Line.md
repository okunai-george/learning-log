+  echo — Вывод текста (эхо)
```Bash
echo Hello World!
```
	Вывод: Hello World!

- pwd — (Print Working Directory) Выводит путь к текущей директории
```Bash
pwd
```
	Вывод: /Users/grigorijklopov

- cd —(Change Directory) Меняет рабочую директорию
```Bash
cd /home/pete # Абсолютный путь, начиная с корня
cd Hawaii # Относительный путь
cd . # Обозначает каталог в котором вы сейчас
cd .. # Перейти в родительский каталог
cd ~ # Перейти в персональный каталог (/Users/grigorijklopov)
cd - # Перейти в предыдущий каталог (в котором были до этого)
```

- ls (List Directories) — Выводит список директорий и файлов
```bash
ls # Или ls . для текущей директории
ls /Users/grigorijklopov # Для абсолютного пути
ls Music # Для относительного пути
```

_Флаги:_
```bash
ls -a # Показывает все файлы/директории (скрытые +)
ls -l # (long) Показывает длинный формат информации о каталоге/файле (разрешения, кол-во ссылок, имя владельца, размер, дата последнего изменения, имя)
ls -r # Выводит список в обратном алфавитном порядке
```

- touch — команда создания файла/файлов или обновления временных меток. Если использовать команду на существующем файле, временные метки обновятся на текущие.
```bash
touch file1.txt
touch file1.txt file2.txt file3.txt
```

_Флаги:_
```bash
touch -r file1.txt file2.txt # Устанавливает временные метки файла 2 как у файла 1
touch -d "2023-01-01 12:30:00" file1.txt # Устанавливает файлу дату
```

- file —  показывает информацию о файле
```bash
file file.txt
```

- cat (concatenate) — конкатенирование. Выводит содержание файла/файлов. Также может вывести содержание в другой документ
```bash
cat file1.txt # Выводит содержание файла
cat file1.txt file2.txt # Выводит последовательно содержание 2 файлов
cat > newfile.txt # Перенаправляет вывод в новый файл
```

- less — Показывает вывод файла в страничном виде.
Навигация:
	- Стрелки
	- Go to start: g
	- Go to end: G
	- Help menu: h
	- Quit : q
Команды:
	/search_term : ищет в прямом направлении
	?search_term : ищет в обратном направлении
	n : переходит к следующему найденному выражению
	N : переходит к предыдущему найденному выражению
```bash
less file1.txt
```

- history — показывает историю ввода
	- Up_Arrow : ввод предыдущей команды
	- !! : запустить прошлую команду еще раз

Команды:
	- `Ctrl-R` : Поиск
	- history -c : (Clear) Очистить историю
	- history -w : Сохранить историю в файл
	- history -d <num> : (Delete) Удалит ввод с номером num

```bash
history
history -cwd
```
- mkdir — (Make Directory) Создает новую директорию (папку).
```bash
mkdir new_folder # Создает одну папку в текущей директории
mkdir folder1 folder2 folder3 # Создает несколько папок сразу
mkdir -p path/to/nested/folder # Флаг -p создает всю цепочку вложенных папок
```

- cp — (Copy) Копирует файлы или директории.
```bash
cp file.txt copy_file.txt # Копирует файл в этой же папке с новым именем
cp file.txt /path/to/folder/ # Копирует файл в другую директорию
cp -r folder1 folder2 # Флаг -r для рекурсивного копирования папок с их содержимым
cp -i file.txt /folder/ # Флаг -i (интерактивный) спросит подтверждение перед перезаписью
```

- mv — (Move) Перемещает или переименовывает файлы и директории.
```bash
mv old_name.txt new_name.txt # Переименование файла/директории
mv file.txt /path/to/folder/ # Перемещение файла в другую папку
mv -i file.txt /folder/ # Флаг -i спросит подтверждение перед перезаписью
```

- rm — (Remove) Удаляет файлы или директории БЕЗВОЗВРАТНО (мимо корзины).
```bash
rm file.txt # Удаляет файл
rm file1.txt file2.txt # Удаляет несколько файлов
rm -r folder_name # Флаг -r для рекурсивного удаления папки и её содержимого
rm -f file.txt # Флаг -f (force) удаляет принудительно без запросов и ошибок
rm -rf folder_name # Самая опасная команда — удаляет папку со всем содержимым без предупреждений
```

- find — Поиск файлов и директорий по различным критериям.
```bash
find . -name "document.txt" # Ищет файл по точному имени в текущей директории (.) и подпапках
find /home -name "*.txt" # Ищет все файлы .txt в директории /home
find . -type d # Ограничить поиск только директориями (папками)
find . -type f # Ограничить поиск только файлами
find . -iname "photo.jpg" # Флаг -iname ищет без учета регистра (найдет и Photo.JPG, и photo.jpg)
```

- help — Встроенная справка для команд самой оболочки (shell builtins).
```bash
help cd # Показывает документацию по встроенной команде cd
```

- man — (Manual) Вызов подробного официального руководства для утилит Linux.
```bash
man ls # Открывает мануал по ls (навигация как в less: стрелки, / для поиска, q для выхода)
```

- whatis — Выводит очень краткое описание команды в одну строку.
```bash
whatis mkdir # Пример вывода: mkdir (1) - make directories
```

- alias — Создание псевдонимов (сокращений) для команд.
```bash
alias ll="ls -la" # Теперь ввод ll выполнит ls -la
alias ..="cd .." # Быстрый переход на уровень выше
unalias ll # Удаляет созданный алиас
```

- exit — Завершает текущую сессию терминала (закрывает вкладку/окно).
```bash
exit
```
